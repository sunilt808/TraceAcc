## High-Impact Resume Bullets

- **Architected a Full-Stack AML Engine:** Engineered a fraud detection platform using **FastAPI** and **React**, reducing manual transaction review time by simulating automated graph heuristic analysis.
- **Implemented Graph Algorithms:** Developed cycle detection (DFS with lexicographic pruning) and fan-in/fan-out hub identification using **NetworkX** to expose multi-hop money laundering networks and shell account chains.
- **Integrated Machine Learning:** Applied unsupervised anomaly detection models (**Isolation Forest, LOF, DBSCAN** via **scikit-learn**) on structural behavioral features to flag sophisticated fraud topologies.
- **Optimized Data Pipeline:** Designed a chunk-based CSV ingestion service using **Pandas/Polars** that processes bulk transaction logs and builds directed dependency graphs for real-time visualization.
- **Interactive Data Visualization:** Integrated **Cytoscape.js** into a modern React dashboard with custom glassmorphic UI, allowing security analysts to visually explore money mule networks and anomaly risk heatmaps.
- **Secure Backend Architecture:** Deployed a **PostgreSQL** database with **SQLAlchemy ORM** for persistent case management and audit logging, secured via **JWT-based authentication** and Role-Based Access Control (RBAC).
